# NIGHTSHIFT documentation

This folder contains static reference pages for the OlympTrade WebSocket client. The Python runtime does not load these pages or require their web assets. The pages are static and may request external font or JavaScript assets from their listed CDNs when viewed in a browser.

For local use, open `index.html` in a browser or run `python -m http.server 8000 --directory docs` from the project root.

Do not publish access tokens, cookies, account identifiers, raw session logs, or other private account data in documentation or issue reports.
